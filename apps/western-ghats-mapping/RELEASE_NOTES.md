## Western Ghats Mapping – Version 1 – Original (1.0.1)

1.0.1: all original images and fliers now come by themselves. The Images and Fliers tabs fetch each picture from the public Pictures and Fliers pack on the IBIN Apps releases page the first time it is shown (internet needed once; the computer keeps a copy for offline use). Installing the pack is no longer needed; an installed pack folder is still used when present. Everything else is as before.

The 2015 program "Western Ghat Resource Assessment and Mapping" (Distribution, Taxonomy & Diversity of Plants of Western Ghats) rebuilt so that it looks and works as the original did, without MapInfo.

- 5,103 plant species, 3,231 map grids, 68,895 common names, 49,758 synonyms, 162,970 distribution records.
- Gridwise search, ten thematic maps (Trees, Herbs, Shrubs, Epiphytes, Regeneration, Total species, Disturbance index, Developmental threat, Harvest threat index, Total threat) with the original's class limits and shades, search by common name or taluk or scientific name, and one page per species (taxonomy, distribution map, images, fliers, distribution data, synonyms, common names).
- Map layers as in the original: Grids, Places, Roads, Railroads, Taluks, Districts, States.
- One picture per species is built in. All the original images (32,012) and fliers (2,030 slides for 1,015 species) are in the separate private **Pictures and Fliers pack**; install it once and it is found automatically.
