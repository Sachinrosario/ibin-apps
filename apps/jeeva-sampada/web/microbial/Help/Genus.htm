General Information
  • This gives the Introduction page for Genus. It consists of
    1. Image of the Genus (missing in few cases).
    2. Brief description of Genus (some are yet to be incorporated).
  • If the list of Genus is empty then:
    Click on the "Click Here To Get List Of Genus" Button to get the list of Genera Under Selected Group(It will take some time to fill the list)
  • Select a Genus name from the list.
    • One can select the Genus name :
      1. Manually by scrolling the list for Genus name.
      2. Automatically by typing the name of the Genus in the box given above the list.
  • To view the Species Details of a Particular Group,Genus:
    Click on the "Forward" Arrow.
  • To view the Page that contains the Group Information:
    Click on the "Backward" Arrow.
