General Information
  • This Provides Introduction page to Microbial Resources that includes the following:
    1. What are Microbial Resources?
    2. What are Microbes?
    3. Where do we find them?
    4. Summary of data collected so far.
  • Provides links to:
    1. State and District wise Geographical Analysis of Groups/Genus/species/Strains.
    2. Reports based upon Habitat, Hazardous Information, Preservation Method and Important from Point of view (like agriculture, medical, industrial etc.).
    3. Zone, State and District wise Numerical Analysis of Groups/Genus/Species/Strains.
  • "Search" Button (at the bottom of the introduction page for microbes) to search a microorganism in Database.
    Search button is very useful if one does not know about the hierarchal details of the microbes i.e. if one does not know about a Group/Genus details of a particular organism then he can search by the name of any Genus or any Species. All details about that organism will be displayed on the screen.
To Make A Search
  1. Type the name of organism that one wants to search.
  2. Click on "Search" Button to perform the search.
  • If the typed organism is a genus name then search list will contain the name of genus with its group name.
  • If the typed organism is species name then search list will display all the possible combinations of Group and Genus with Species name that belongs to that particular species.
  • After viewing the search results in the list, one can select and view the details of the Group/Genus/Species by clicking on the "GO" Button.
  • Introduction page (html page) for the Group of microorganism will appear. It Contains:.
    1. Few images that belongs to that Group.
    2. Brief description of the Group.
  • Click "Forward" arrow to view the Introduction page (html page) for the Genus of Microorganism. It consists of:
    1. Image of Genus (some may be missing).
      2. Brief description of the Genus (some are yet to be incorporated).
  • Click "Forward" arrow to view the list of Species and strains that belongs to that Group and Genus if the microorganism typed is a species name.
