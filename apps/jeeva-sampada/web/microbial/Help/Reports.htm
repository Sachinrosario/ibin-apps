General Information
  • Numerical Analysis can be done as following:
    1. Zonal Distribution
    2. Total Records - Zone wise
    3. Total Records - State Wise
    4. Total records - District wise
    5. Group Distribution - Zone wise
    6. Group Distribution - State wise
    7. Group Distribution - District wise.
    8. Genus Distribution - Zone wise
    9. Genus Distribution - State wise
    10. Genus Distribution - District wise>
    11. Species Distribution - Zone wise
    12. Species Distribution - State wise
    13. Species Distribution - District wise
Zonal Distribution
  • Select the option - "Zonal Distribution"
  • Click on "Build Report" Button.
  • It will give:
    1. Zone wise Distribution of All Strains.
    2. Zone wise distribution of Each Group (Actinomycetes, Bacteria, Fungi, Yeasts, Algae etc.).
Zone Wise Distribution
  • Select the option-"Total Records -Zone wise."
  • Click on "Build Report" Button.
  • It will give:
    1. Zone wise distribution for all strains.
Total Records - State Wise
  • Select the option-"Total Records -State wise."
    • Dropdown box named Group becomes visible.
      By default "All Groups" from the dropdown box is selected.
  • Reports that can be generated are:
    • State wise distribution of All Groups.
    • Group Wise and State Wise Distribution of strains.
      • select a particular group from the dropdown box named Group.
  • Click on "Build Report" Button. It will give Group wise and State wise distribution of Strains
Total Records - District wise
  • Select the option-"Total Records -District wise."
  • Dropdown box named State will become visible.
  • Select a particular State from dropdown box.
  • Click on "Build Report" Button.
  • It will give:
    • District wise Distribution of all strains for the selected State.
Group Distribution - Zone wise
  • Select the option-"Group Distribution - Zone Wise."
  • The dropdown boxes named Zone and Group will become visible.
  • Reports that can be generated using combinations of Groups and Zones are:
    1. Group wise distribution for All Zones.
      • Select All Zones from dropdown box named Zone and All Groups from dropdown box named Groups.
      • Click on "Build Report" Button.
    2. Distribution of particular Group for All Zones.
      • Select All Zones from dropdown box named Zone and a Group from dropdown box named Groups.
      • Click on "Build Report" Button.
    3. Group Distribution for a particular Zone.
      • Select A Zone from dropdown box named Zone and All Groups from dropdown box named Groups.
      • Click on "Build Report" Button.
    4. Group Distribution for a particular Group and particular Zone.
      • Select A Zone from dropdown box named Zone and A Group from dropdown box named Groups.
      • Click on "Build Report" Button.
Group Distribution - State wise
  • Select the option-"Group Distribution - State Wise."
  • Dropdown box named State will become visible.
  • Select a particular State.
  • Click on "Build Report" Button.
Group Distribution - District wise
  • Select the option-"Group Distribution - District Wise."
  • Dropdown box named State and Group will become visible.
  • Reports that can be generated using various combinations of State and Group.
    1. Group Distribution for A State and All Groups.
      • Select a State and All Groups from dropdown boxes.
      • Click on "Build Report" Button.
    2. Group Distribution for A State and A Group
      • Select a State from dropdown box name State and A Group from dropdown box named Groups.
      • Click on "Build Report" Button.
Genus Distribution - Zone wise
  • Select the option-"Genus Distribution - Zone Wise."
  • Dropdown boxes named Zone and Group will become visible.
  • The Reports that can be generated using the combinations of Zones and Group
    1. Genus Distribution for All Zones and A Group
      • Select All Zones from the dropdown box named Zone and A Group from dropdown box named Group.
      • Click on "Build Report" Button.
    2. Genus Distribution for A Zone and A Group
      • Select a Zone from dropdown box named Zone and a Group from dropdown box named Group.
      • Click on "Build Report" Button.
Genus Distribution - State wise
  • Select the option-"Genus Distribution - State Wise."
  • Dropdown boxes named State and Group will become visible.
  • Reports can be built using the combination of State and Group are:
    1. Genus Distribution for A State and All Groups.
      • Select a particular state from the dropdown box named State and All Groups from the dropdown box named Group.
      • Click on "Build Report" Button.
    2. Genus Distribution for a State and A Group
      • Select a particular state from the dropdown box named State and A Group from the dropdown box named Group.
      • Click on "Build Report" Button.
Genus Distribution - District wise
  • Select the option-"Genus Distribution - District Wise."
  • Dropdown boxes for State and Group will become visible.
  • The reports that can be build using the combination of State and District are:
    1. Genus distribution for a State and a Group
      • Select a State and a Group from dropdown boxes named State and Group.
      • Click on "Build Report" Button.
    2. Genus distribution for a State and All Groups
      • Select a State from dropdown box named State and All Groups from Dropdown box named Group.
      • Click on "Build Report" Button.
Species Distribution - Zone wise
  • Select the option-"Species Distribution - Zone Wise."
  • Dropdown boxes for Zone, State, Group, Genus will become visible.
  • Reports that can be generated with the combination of Zone, State, Group, and Genus are:
    1. Zone wise Species Distribution for a State, Group and Genus
    2. Species Distribution for a State, Group, Genus and Zone
    3. Click on "Build Report" Button.
Species Distribution - State wise
  • Select the option-"Species Distribution - State Wise."
  • Dropdown boxes for State, Group, and Genus will become visible.
  • Reports that can be generated with the combination of State, Group, and Genus are:
    • State wise Species distribution for a Group, a State, A genus
  • Click on "Build Report" Button.
Species Distribution - District wise
  • Select the option-"Species Distribution - District Wise."
  • Dropdown boxes for State, Group, and Genus will become visible.
  • Report that can be generated with the combination of State, Group, and Genus is:
    • District wise Species distribution for a Group, a State, and a Genus.
  • Click on "Build Report" Button.
