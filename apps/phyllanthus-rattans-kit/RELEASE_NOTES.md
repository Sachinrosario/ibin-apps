**Version 1 – Original.** Faithful rebuild of the 2010 Indian Barcode of Life identification kit for *Phyllanthus* and rattans (DBT; ATREE Bangalore, UAS Bangalore, BSI Kolkata). Same 59 species, 4 identification keys, images, maps, localities and DNA barcodes; identification results checked against the original database on 1,290 combinations.

**Which file do I download?**

| Computer | File | How |
| --- | --- | --- |
| Windows 10/11 | `PhyllanthusRattansKit_1.0.0_Setup.exe` | Double-click → Next → Install. If Windows says "Windows protected your PC", click **More info → Run anyway**. |
| Windows, no install | `PhyllanthusRattansKit.exe` | Double-click. Runs from any folder or pen drive. |
| Ubuntu 22.04+ | `PhyllanthusRattansKit_1.0.0_amd64.deb` | Double-click → Install. |
| Mac | `PhyllanthusRattansKit_1.0.0_universal.dmg` | Open, drag to Applications; first time right-click → Open. (Added by the build robot.) |
| Any computer | `PhyllanthusRattansKit_1.0.0_offline.zip` | Extract, then double-click **Open Kit.html**. |
