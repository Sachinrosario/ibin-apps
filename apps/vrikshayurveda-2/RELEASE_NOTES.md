## Vrikshayurveda – Version 2 – Scientific names updated (2.0.0)

Version 2 is Version 1 exactly as it was (same screens, same search, same behaviour), with one change: the scientific names are brought up to date.

Proprietary right holder: Dr. K.N. Ganeshaiah · Updated in 2026 by Dr. Sachin A. Rosario

### What changed
- Wherever the 2011 program showed a scientific name that is no longer the accepted one, the 2011 name is kept and the **current accepted name is shown in brackets after it**, for example *Emblica officinalis (Phyllanthus emblica)*. This applies to the plant list of each verse, the species-name box choices and the heading of each species page.
- 41 names were updated by looking up every scientific name in the GBIF Backbone Taxonomy (built on the Catalogue of Life) in October 2026. Spelling slips in the 2011 data (for example *Juaticia gendarussa*) are corrected the same way.
- 11 names were left without a bracket because the lookup gave a doubtful answer; they need a taxonomist's check.
- Searching still works with the 2011 names, because the lookups behind the screens are unchanged.
