## Which file do I download?

| Computer | File | How to install |
| --- | --- | --- |
| Windows 10 / 11 | ends in `_x64-setup.exe` | Double-click → Next → Install. If Windows says "Windows protected your PC", click **More info → Run anyway** (the app is not yet code-signed). |
| Mac | ends in `.dmg` | Open it, drag the app into Applications. First time: right-click the app → **Open** → **Open** (not yet notarized by Apple). |
| Ubuntu | ends in `.deb` or `.AppImage` | `.deb`: double-click to install. `.AppImage`: right-click → Properties → Permissions → Allow executing, then double-click. |
| Any computer, no install | ends in `_offline.zip` | Extract → double-click **Open Kit.html** |
