## Which file do I download?

| Computer | File | How to install |
| --- | --- | --- |
| Windows 10 / 11 | ends in `_Setup.exe` (or the plain `.exe`, which runs without installing) | Double-click → Next → Install. If Windows says "Windows protected your PC", click **More info → Run anyway** (the app is not yet code-signed). |
| Mac | ends in `_universal.dmg` | Open it, drag the app into Applications. First time: right-click the app → **Open** → **Open** (not yet notarized by Apple). |
| Ubuntu | ends in `_amd64.deb` | Double-click to install (or `sudo apt install ./<file>.deb`). |
| Any computer, no install | ends in `_offline.zip` | Extract → double-click **Open Kit.html** |

All versions of an app can be installed on the same computer.
